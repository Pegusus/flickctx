How it works

One path for every ask — crop first, tools second.

  1. 01

    Mark

    Freehand around a metric, diagram, error, or UI fragment.

  2. 02

    Capture

    Crop becomes the primary image; full display rides along as context. Frontmost app/URL tagged when available.

  3. 03

    Ask & continue

    Vision agent answers from the pixels, then you keep chatting on the same mark.

Install

MIT licensed. Runs as a local Electron app.

git clone https://github.com/Pegusus/flickctx.git
cd flickctx
npm install
npx flickctx config --api-key sk-ant-... --model claude-sonnet-4-5
npm start

Then press ⌘⇧F / Ctrl+Shift+F, draw, and ask. On macOS, enable Screen Recording for the app.
