Flickctx

Follow an incident across tabs — mark the spike, mark the log, ask what connects them.

Clone the repo npm start

Run it locally

Electron app. Freehand mark → JPEG vision crop + full-screen context + frontmost app hint → multi-turn chat. 

git clone https://github.com/Pegusus/flickctx.git
cd flickctx && npm install
npx flickctx config --api-key sk-ant-… --model claude-sonnet-4-5
npm start   # then ⌘⇧F / Ctrl+Shift+F
