How it works

Mark. Ask. Keep going.

One hotkey. Freehand around what matters. Type any question — pricing, a diagram, a console, a stack trace. Same path every time.

  1. 01

    Mark

    ⌘⇧F / Ctrl+Shift+F — draw freehand. The crop becomes the primary vision focus; the full display stays as context.

  2. 02

    Ask

    Your question goes in verbatim. No per-question prompt tricks — the model sees the pixels and reasons.

  3. 03

    Chat

    Follow-ups stay on the same mark. Dig into the spike, compare tabs, or pull the matching code from a local repo.

Vision grounding

It looks at what you marked — not a guess from the FAQ.

Flickctx sends a JPEG crop of your mark, a wider context frame, and whatever frontmost-app hint it can detect. Answers stay tied to the pixels on screen.

  • Primary crop Freehand → bounding box → resized JPEG for the vision API
  • Context frame Full display so the model sees surrounding UI and tabs
  • Frontmost hint App name / browser URL when the OS can provide it
  • Multi-monitor Overlay tracks the display you marked on

Local + web tools

From the mark to your repos and the web.

When the screenshot isn’t enough, Flickctx can search the web, fetch a URL, or dig through the repos you configured — without leaving the chat on that mark.

  • web_search Look up docs, status pages, release notes
  • fetch_url Pull a specific page into the turn
  • list_local_repos Ambient catalog of your search roots
  • grep_local / read_local_file Find the handler that matches the error
  • list_skills / read_skill Load product playbooks only when needed
  • repo_details Orient on a checkout before diving in

Desktop companion

Electron overlay. Your API key. MIT.

Runs locally. On macOS, grant Screen Recording to Electron in System Settings, then restart. Optional Cloudflare Worker proxy keeps the key off each laptop.

Get it running

Install

git clone https://github.com/Pegusus/flickctx.git
cd flickctx && npm install
export ANTHROPIC_API_KEY=sk-ant-…
npx flickctx config --model claude-sonnet-4-5
npx flickctx config --search-roots "$HOME/code,$HOME/Projects"
npm start

Then ⌘⇧F / Ctrl+Shift+F — draw freehand, ask, keep chatting.
